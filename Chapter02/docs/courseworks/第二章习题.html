2.4

计算并画出 \(y[n] = x[n] * h[n]\)，其中：

\[ x[n] = \begin{cases} 1, & 3 \le n \le 8 \\ 0, & \text{其他} \end{cases} \]

\[ h[n] = \begin{cases} 1, & 4 \le n \le 15 \\ 0, & \text{其他} \end{cases} \]

1. 卷积范围与性质分析

  • 信号长度：
    • \(x[n]\) 的长度 \(L_1 = 8 - 3 + 1 = 6\)
    • \(h[n]\) 的长度 \(L_2 = 15 - 4 + 1 = 12\)
  • 非零范围：
    • 起点：\(n_{start} = 3 + 4 = 7\)
    • 终点：\(n_{end} = 8 + 15 = 23\)
  • 波形特征： 由于两个信号都是矩形脉冲，卷积结果为一个梯形。其最大值为 \(\min(L_1, L_2) = 6\)。

2. 数值计算过程

根据重叠情况分段讨论：

\(n\) 的范围 状态 计算式 \(y[n]\)
\(n < 7\) 无重叠 \(0\) \(0\)
\(7 \le n \le 12\) 逐渐进入 \(\sum_{k=3}^{n-4} 1\) \(n-6\)
\(13 \le n \le 18\) 完全进入(平顶) \(\sum_{k=3}^{8} 1\) \(6\)
\(19 \le n \le 23\) 逐渐离开 \(\sum_{k=n-15}^{8} 1\) \(24-n\)
\(n > 23\) 完全离开 \(0\) \(0\)

3. 卷积波形图 \(y[n]\)

signalData = {
  const y = [];
  for (let n = 5; n <= 25; n++) {
    let val = 0;
    if (n >= 7 && n <= 12) val = n - 6;
    else if (n >= 13 && n <= 18) val = 6;
    else if (n >= 19 && n <= 23) val = 24 - n;
    y.push({ n: n, value: val });
  }
  return y;
}

2.11

已知信号： - \(x(t) = u(t-3) - u(t-5)\) （宽度为 2 的矩形脉冲） - \(h(t) = e^{-3t}u(t)\) （指数衰减信号）

我们需要求解： 1. \(y(t) = x(t) * h(t)\) 2. \(g(t) = \frac{dx(t)}{dt} * h(t)\) 3. 两者的关系

(a) 计算 \(y(t) = x(t) * h(t)\)

利用卷积的线性移位性质。先求单位阶跃信号的卷积： \[f(t) = u(t) * (e^{-3t}u(t)) = \int_{0}^{t} e^{-3\tau} d\tau = \frac{1}{3}(1 - e^{-3t})u(t)\]

根据 \(x(t) = u(t-3) - u(t-5)\)，代入得： \[y(t) = \frac{1}{3}(1 - e^{-3(t-3)})u(t-3) - \frac{1}{3}(1 - e^{-3(t-5)})u(t-5)\]

(b) 计算 \(g(t) = \frac{dx(t)}{dt} * h(t)\)

首先对 \(x(t)\) 求导，得到一对冲击信号： \[\frac{dx(t)}{dt} = \delta(t-3) - \delta(t-5)\]

利用冲击信号的卷积性质 \(\delta(t-t_0) * h(t) = h(t-t_0)\)： \[g(t) = h(t-3) - h(t-5)\] \[g(t) = e^{-3(t-3)}u(t-3) - e^{-3(t-5)}u(t-5)\]

(c) \(g(t)\) 与 \(y(t)\) 的关系

根据卷积的微分性质： \[\frac{d}{dt}[x(t) * h(t)] = \frac{dx(t)}{dt} * h(t)\]

因此得出结论： \(g(t)\) 是 \(y(t)\) 对时间 \(t\) 的一阶导数，即： \[g(t) = \frac{dy(t)}{dt}\]

2.17

考虑一个由一阶微分方程描述的线性时不变（LTI）系统：

\[\frac{d}{dt}y(t) + 4y(t) = x(t)\]

初始条件：系统满足初始松弛（Initial Rest），即若 \(x(t)=0, t < t_0\)，则 \(y(t)=0, t < t_0\)。这意味着系统是因果的。

2. (a) 复指数激励响应

当输入为 \(x(t) = e^{(-1+3j)t}u(t)\) 时：

系统函数

由微分方程可知，系统函数为： \[H(s) = \frac{1}{s + 4}\]

特解计算

令 \(s = -1 + 3j\)，代入系统函数： \[H(-1+3j) = \frac{1}{(-1+3j)+4} = \frac{1}{3+3j} = \frac{1-j}{6}\]

全响应（暂态 + 稳态）

\[y(t) = \frac{1-j}{6} \left( e^{(-1+3j)t} - e^{-4t} \right) u(t)\]

3. (b) 实数激励响应

当输入为 \(x(t) = e^{-t}\cos(3t)u(t)\) 时，利用线性性质： \[x(t) = \text{Re}\{ e^{(-1+3j)t} u(t) \}\]

因此输出为 (a) 小题结果的实部： \[y(t) = \text{Re} \left\{ \frac{1-j}{6} \left( e^{(-1+3j)t} - e^{-4t} \right) \right\} u(t)\]

化简结果

\[y(t) = \frac{1}{6} \left[ e^{-t}(\cos 3t + \sin 3t) - e^{-4t} \right] u(t)\]

2.23

已知 \(y(t) = x(t) * h(t)\)，其中 \(x(t) = \sum_{k=-\infty}^{+\infty} \delta(t - kT)\)。

利用卷积的移位性质： \[y(t) = \sum_{k=-\infty}^{+\infty} h(t - kT)\]

这是信号 \(h(t)\) 的周期延拓。

交互式波形观察

你可以调节下方的 \(T\) 值，观察 \(T=4, 2, 1.5, 1\) 时波形的演变。

Code 
viewof T = Inputs.range([0.8, 4], {step: 0.1, label: "周期 T", value: 4});

t_range = d3.range(-5, 5, 0.02);

// 定义三角脉冲 h(t)
function h(t) {
  return Math.max(0, 1 - Math.abs(t));
}

// 计算叠加后的 y(t)
data = t_range.map(t => {
  let sum = 0;
  for (let k = -10; k <= 10; k++) {
    sum += h(t - k * T);
  }
  return { t, y: sum };
});

Plot.plot({
  grid: true,
  y: { domain: [0, 1.5], label: "y(t)" },
  x: { label: "t" },
  marks: [
    Plot.lineY(data, {x: "t", y: "y", stroke: "red"}),
    Plot.ruleY([0])
  ]
})
