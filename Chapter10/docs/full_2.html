11.1 线性反馈的基本原理

H(s), H(z)：前向通路系统函数
G(s), G(z)：反馈通路系统函数
Q(s), Q(z)：闭环系统函数

\[ Q(s) = \frac{H(s)}{1 + G(s)H(s)}, \quad Q(z) = \frac{H(z)}{1 + G(z)H(z)} \]

 不稳定系统的稳定化

示例 3：

\[ \begin{array}{l} H(s) = \frac{b}{s - a}，\quad a > 0 \text{ 时不稳定} \\ Q(s) = \frac{H(s)}{1 + K H(s)} = \frac{b}{s - a + K b} \end{array} \]

\[ \text{当 } K > \frac{a}{b} \text{ 时稳定} \]

当 \(0 < K_2 b < 1\) 且 \(K_1 b > a\) 时稳定

示例 6：

\[ H(z) = \frac{1}{1 - 2z^{-1}} = \frac{z}{z - 2} \]

\[ G(z) = 2\beta z^{-1} = \frac{2\beta}{z} \]

\[ Q(z) = \frac{1}{1 - 2(1 - \beta)z^{-1}} = \frac{z}{z - 2(1 - \beta)} \]

\[ \text{极点 } z = 2(1 - \beta) \]
