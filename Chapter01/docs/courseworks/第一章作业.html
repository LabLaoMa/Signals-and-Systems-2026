信号与系统第一章习题解析

离散时间信号的周期性分析

习题 1.9 (d)

题目内容： 判断下列信号的周期性。若是周期的，给出其基波周期。

\[x_4[n] = 3e^{j3\pi(n + 1/2)/5}\]

第一步：标准形式展开

为了便于分析，我们将原表达式展开，分离出与 \(n\) 相关的项：

\[x_4[n] = 3 e^{j \frac{3\pi}{10}} \cdot e^{j \left( \frac{3\pi}{5} \right) n}\]

  • 振幅部分：\(3 e^{j \frac{3\pi}{10}}\) 是一个复常数，不影响周期性。
  • 核心项：\(e^{j \omega_0 n}\)，其中角频率 \(\omega_0 = \frac{3\pi}{5}\)。

第二步：周期性判定

对于离散时间复指数信号，其周期性取决于 \(\frac{\omega_0}{2\pi}\) 是否为有理数：

\[\frac{\omega_0}{2\pi} = \frac{3\pi / 5}{2\pi} = \frac{3}{10}\]

Note

因为 \(\frac{3}{10}\) 是有理数（可表示为两整数之比），所以该信号是周期性的。

第三步：确定基波周期 \(N\)

基波周期 \(N\) 必须是满足以下条件的最小正整数： \[\omega_0 N = 2\pi m \quad (m \in \mathbb{Z})\]

将其写为最简分数形式： \[\frac{\omega_0}{2\pi} = \frac{m}{N} = \frac{3}{10}\]

由于 \(3\) 和 \(10\) 已经互质（不可再约分），我们直接得到： \(N = 10\)

总结

  • 结论：该信号为周期信号。
  • 基波周期：\(N = 10\)。

教学提示：注意离散信号与连续信号的区别。连续信号 \(e^{j \omega_0 t}\) 只要 \(\omega_0 \neq 0\) 永远是周期的，但离散信号要求频率与 \(2\pi\) 之比必须是有理数。

习题 1.10：连续时间信号组合

题目： 求 \(x(t) = 2\cos(10t + 1) - \sin(4t - 1)\) 的基波周期。

求解步骤

  1. 提取分量周期：

    • 对于 \(2\cos(10t + 1)\)：\(\omega_1 = 10 \implies T_1 = \frac{2\pi}{10} = \frac{\pi}{5}\)
    • 对于 \(-\sin(4t - 1)\)：\(\omega_2 = 4 \implies T_2 = \frac{2\pi}{4} = \frac{\pi}{2}\)

  2. 寻找最小公倍数： \[\frac{T_1}{T_2} = \frac{\pi/5}{\pi/2} = \frac{2}{5}\]

  3. 确定基波周期 \(T\)： \[T = 5 T_1 = 2 T_2 = \pi\]

结论： 基波周期 \(T = \pi\)。

习题 1.27 判定标准回顾

对于一个系统，我们需要判定以下五个性质：

  1. 无记忆性 (Memoryless): 输出 \(y(t)\) 仅取决于同一时刻的输入 \(x(t)\)。
  2. 时不变性 (Time-Invariant): 输入的延迟导致输出出现同样的延迟。
  3. 线性 (Linear): 满足叠加性与齐次性。
  4. 因果性 (Causal): 输出不取决于未来的输入。
  5. 稳定性 (Stable): 有界输入产生有界输出 (BIBO)。

(b) \(y(t) = [\cos(3t)]x(t)\)

  • 无记忆性：是。\(y(t)\) 仅取决于当前时刻的 \(x(t)\)。
  • 时不变性：否。系数 \(\cos(3t)\) 随时间变化。
    • 证明：令输入为 \(x_1(t) = x(t-t_0)\)，则 \(y_1(t) = \cos(3t)x(t-t_0)\)。
    • 而 \(y(t-t_0) = \cos(3(t-t_0))x(t-t_0)\)。两者不等。
  • 线性：是。
  • 因果性：是。
  • 稳定性：是。因为 \(|\cos(3t)| \le 1\)，若 \(|x(t)| < M\)，则 \(|y(t)| < M\)。

(c) \(y(t) = \int_{-\infty}^{2t} x(\tau) d\tau\)

  • 无记忆性：否。积分运算显然涉及过去（甚至未来）的值。
  • 时不变性：否。存在时间伸缩（\(2t\)）。
  • 线性：是。积分具有线性性质。
  • 因果性：否。
    • 理由：当 \(t > 0\) 时，积分上限 \(2t > t\)。例如 \(y(1)\) 取决于 \(x(\tau)\) 在 \(\tau \in [1, 2]\) 的值（未来）。
  • 稳定性：否。
    • 反例：若 \(x(t) = u(t)\)，则 \(t \to \infty\) 时，\(y(t) \to \infty\)。

(d) 分段系统分析

\[y(t) = \begin{cases} 0, & t < 0 \\ x(t) + x(t-2), & t \ge 0 \end{cases}\]

  • 无记忆性：否。包含 \(x(t-2)\) 项。
  • 时不变性：否。系统规则在 \(t=0\) 发生突变。
  • 线性：是。
  • 因果性：是。\(y(t)\) 仅取决于 \(x(t)\) 和 \(x(t-2)\)，均非未来时刻。
  • 稳定性：是。若 \(x(t)\) 有界，则其和必有界。

时不变 否 否 否

因果 是 否 是
