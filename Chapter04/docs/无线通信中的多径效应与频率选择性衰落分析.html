无线通信中的多径效应与频率选择性衰落分析

Author

Gemini AI

Published

April 8, 2026

1. 物理模型描述 (Physical Model)

在无线通信场景中，接收端（Receiver）收到的信号往往不仅仅是基站发送的直射波，还包含经过障碍物反射后的反射波。

时域表达式

假设发送端信号为 \(x(t)\)，接收端收到的信号 \(y(t)\) 可以表示为两个分量的叠加： \[y(t) = a_0 x(t) + a_1 x(t - \tau)\]

其中： - \(a_0, a_1\)：直射路径与反射路径的增益系数。 - \(\tau\)：由于路径差导致的时延。

2. 频域推导 (Frequency Domain Analysis)

为了观察多径对信号质量的影响，我们利用傅里叶变换（Fourier Transform）将其转换至频域。

系统函数

利用位移性质 \(\mathcal{F}\{x(t-\tau)\} = X(j\omega)e^{-j\omega\tau}\)，得到： \[Y(j\omega) = a_0 X(j\omega) + a_1 e^{-j\omega\tau} X(j\omega) = (a_0 + a_1 e^{-j\omega\tau}) X(j\omega)\]

矩形脉冲的频谱

若发送信号 \(x(t)\) 是一个脉宽为 \(2T\) 的矩形脉冲，其频谱为经典的 Sinc 函数： \[X(j\omega) = \frac{2 \sin(\omega T)}{\omega}\]

特定条件下的合成频谱

当 \(a_0 = a_1 = 1\) 时（即两路信号强度相等），利用欧拉公式 \(\cos \theta = \frac{e^{j\theta} + e^{-j\theta}}{2}\)，可以推导出： \[Y(j\omega) = 4 e^{-j\omega\tau/2} \cos\left(\frac{\omega\tau}{2}\right) \frac{\sin(\omega T)}{\omega}\]

3. 核心现象：频率选择性衰落

通过观察 \(|Y(j\omega)|\) 的波形，我们可以发现原本平滑的信号频谱被叠加了一个周期性的余弦包络 \(| \cos(\frac{\omega\tau}{2}) |\)。

  • 频谱“凹陷” (Spectral Nulls)：当 \(\frac{\omega\tau}{2} = n\pi + \frac{\pi}{2}\) 时，该频率分量的增益为 0。
  • 结论：不同的频率分量经历了不同的衰减，这种现象被称为 频率选择性衰落 (Frequency Selective Fading)。

4. 应用层面与工程意义

4.1 符号间干扰 (ISI)

在时域上，时延 \(\tau\) 会导致前后两个脉冲信号重叠，产生符号间干扰。如果 \(\tau\) 接近信号周期 \(T\)，接收端将很难分辨原始数据。

4.2 现代通信的对策：OFDM

为了对抗这种“频谱凹陷”，4G/5G 采用了 OFDM (正交频分复用) 技术： * 将宽带信号切分为许多窄带子载波。 * 即使某些子载波掉进了“频谱凹陷”导致失真，其他子载波依然可以正常工作。 * 配合信道编码（纠错码），可以完美还原数据。

4.3 雷达与信道估计

在工程实践中，我们可以通过发送已知信号（训练序列），观测接收端的 \(Y(j\omega)\) 情况，反向计算出环境的时延 \(\tau\) 和反射系数 \(a\)。这是 信道估计 (Channel Estimation) 和 雷达定位 的基础。
