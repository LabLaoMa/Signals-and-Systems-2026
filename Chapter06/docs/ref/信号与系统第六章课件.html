§6．2．2 Group delay（群延时）

Consider a narrowband signal \(\quad \Delta \omega \ll \omega_{0}\)窄带信号

\[ \begin{aligned} & X(j \omega)=\left\{\begin{array}{ll} \neq 0 & \left|\omega-\omega_{0}\right|<\frac{\Delta \omega}{2} \\ 0 & \left|\omega-\omega_{0}\right|>\frac{\Delta \omega}{2} \end{array} \quad \angle H(j \omega)=-\phi-\omega \alpha\right. \\ & Y(j \omega)=X(j \omega)|H(j \omega)| e^{-j \phi} e^{-j \omega \alpha} \quad \boldsymbol{\alpha}-\text { Group delay } \\ & \text { at } \boldsymbol{\omega}=\boldsymbol{\omega}_{0} \end{aligned} \]

The Group Delay at each frequency

\[ \tau(\omega)=-\frac{d}{d \omega}\{\angle H(j \omega)\} \]

Example: \(y(t)=x\left(t-t_{0}\right)\)

\[ \begin{aligned} & H(j \omega)=e^{-j \omega t_{0}} \\ & \angle H(j \omega)=-\omega t_{0} \\ & \tau(\omega)=t_{0} \quad(\text { signal delay }) \end{aligned} \]

Example 6.1 Consider an all-pass system.

\[ \begin{aligned} & H_{\mathrm{i}}(j \omega)=\frac{1+\left(j \omega / \omega_{i}\right)^{2}-2 j \zeta_{i}\left(\omega / \omega_{i}\right)}{1+\left(j \omega / \omega_{i}\right)^{2}+2 j \zeta_{i}\left(\omega / \omega_{i}\right)} \\ & \left|H_{\mathrm{i}}(j \omega)\right|=1 \Rightarrow|H(j \omega)|=1 \\ & \angle H_{\mathrm{i}}(j \omega)=-2 \operatorname{tg}^{-1}\left\{\frac{2 \zeta_{i}\left(\omega / \omega_{i}\right)}{1-\left(\omega / \omega_{i}\right)^{2}}\right\} \\ & \angle H(j \omega)=\sum_{\mathrm{i}=1}^{3} \angle H_{\mathrm{i}}(j \omega) \\ & \omega / \omega_{i}=f / f_{i} \quad \text { Let }\left\{\begin{array} { l } { f _ { 1 } = 5 0 \mathrm { Hz } } \\ { f _ { 2 } = 1 5 0 \mathrm { Hz } } \\ { f _ { 3 } = 3 0 0 \mathrm { Hz } } \end{array} \left\{\begin{array}{l} \zeta_{1}=0.066 \\ \zeta_{2}=0.033 \\ \zeta_{3}=0.058 \end{array}\right.\right. \end{aligned} \]

\[ \begin{aligned} & \tau \frac{d y(t)}{d t}+y(t)=x(t) \\ & H(j \omega)=\frac{1 / \tau}{j \omega+1 / \tau} \\ & |H(j \omega)|=\frac{1 / \tau}{\sqrt{\omega^{2}+(1 / \tau)^{2}}} \\ & 20 \lg |H(j \omega)|=20 \lg \left[1 /\left(\tau \sqrt{\omega^{2}+(1 / \tau)^{2}}\right)\right] \end{aligned} \]
