波特图推导与理想低通滤波器特性

1 一阶低通系统的对数幅频特性

1.1 传递函数与幅频特性

对于一个典型的单极点一阶低通系统，其频率响应方程为： \[H(j\omega) = \frac{1}{1 + j\omega\tau}\] 其对数模（单位：dB）定义为： \[A(\omega) = 20 \lg |H(j\omega)| = -10 \lg(1 + \omega^2\tau^2)\]

1.2 转折频率处的误差推导

在转折频率 \(\omega = 1/\tau\) 处（即 \(\omega\tau = 1\)），准确的对数模为： \[A(1/\tau) = -10 \lg(1 + 1^2) = -10 \lg 2 \approx -3 \text{ dB}\]

结论： 渐近近似线在转折频率处相交于 \(0 \text{ dB}\) 点，而实际曲线在那一点的高度是 \(-3 \text{ dB}\)，因此最大近似误差为 \(3 \text{ dB}\)。

2 相位特性的折线近似法

2.1 三段式折线方程

一阶低通系统的相位方程为 \(\phi(\omega) = -\arctan(\omega\tau)\)。为了工程方便，我们采用“三段式”折线进行近似。

中间斜线段连接了点 \((0.1/\tau, 0)\) 与 \((10/\tau, -\pi/2)\)。在对数频率轴下，其直线方程为： \[\phi(\omega) = -\frac{\pi}{4} [\lg(\omega\tau) + 1]\]

2.2 斜率与意义

该斜率意味着在转折频率前后的两个十倍频区间内，相位以 \(-45^\circ/\text{dec}\) (或 \(-\pi/4\) 每十倍频) 的恒定斜率线性下降。这种近似将复杂的非线性曲线简化为了一次函数。

3 理想低通滤波器的时域响应

3.1 上升时间与带宽

理想低通滤波器的单位阶跃响应呈现正弦积分 (Si) 函数形状。定义上升时间 \(t_r\) 为输出由最小值到最大值所经历的时间： \[t_r = (t_0 + \frac{\pi}{\omega_c}) - (t_0 - \frac{\pi}{\omega_c}) = \frac{2\pi}{\omega_c} = \frac{1}{f_c}\]

3.2 带宽-上升时间乘积

若令带宽为 \(B = f_c\)，则有： \[B \cdot t_r = 1\] 物理意义： 系统带宽越窄，上升时间越长，响应越慢。这是工程中“带宽换取快速性”的核心折中。

4 常见滤波器类型总结

滤波器类型 核心特性
巴特沃斯 通带最大平坦，无纹波。
切比雪夫 过渡带更陡峭，但通带(I型)或阻带(II型)有纹波。
椭圆 (Cauer) 过渡带最陡，通阻带均有纹波。
贝塞尔 最平坦群延迟，保持波形无失真，无过冲。
高斯 时频域均为高斯分布，完全无振铃效应。
