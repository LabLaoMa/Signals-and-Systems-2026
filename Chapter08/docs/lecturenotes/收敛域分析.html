拉普拉斯变换实例分析：指数信号

实例：\(x(t) = e^{-at}u(t)\) 的拉普拉斯变换

对于信号 \(x(t) = e^{-at}u(t)\)，其拉普拉斯变换定义为：

\[ X(s) = \int_{-\infty}^{\infty} e^{-at}u(t)e^{-st} dt = \int_{0}^{\infty} e^{-(s+a)t} dt \]

计算积分得：

\[ X(s) = \lim_{T \to \infty} \left[ \frac{1 - e^{-(s+a)T}}{s + a} \right] = \frac{1}{s + a} \]

为什么收敛域 (ROC) 是 \(Re \{s\} > -Re \{a\}\)？

收敛域取决于积分 \(\int_{0}^{\infty} e^{-(s+a)t} dt\) 是否存在（即是否趋于有限值）。

1. 数学推导

设复变量 \(s = \sigma + j\omega\)，复常数 \(a = a_r + ja_i\)。 则指数项的模为： \[|e^{-(s+a)t}| = |e^{-(\sigma + a_r)t} \cdot e^{-j(\omega + a_i)t}| = e^{-(\sigma + a_r)t}\]

为了使 \(t \to \infty\) 时积分收敛，指数部分的指数必须为负数： \[-(\sigma + a_r) < 0 \implies \sigma > -a_r\]

写成复数形式即为： \[Re \{s\} > -Re \{a\}\]

2. 物理意义与稳定性分析

根据 \(Re \{a\}\) 的取值，系统的性质会有所不同：

  • 若 \(Re \{a\} > 0\)：
    • 收敛域包含虚轴 (\(j\omega\) 轴)。
    • 傅里叶变换存在，且为 \(X(j\omega) = \frac{1}{j\omega + a}\)。
    • 此时信号是平方可积的，系统稳定。
  • 若 \(Re \{a\} < 0\)：
    • 收敛域不包含虚轴。
    • 连续时间傅里叶变换不存在。
    • 此时信号随时间指数增长，系统不稳定。
  • 若 \(Re \{a\} = 0\)（即 \(a\) 为纯虚数 \(j\omega_0\)）：
    • 傅里叶变换仅以冲击函数（分布形式）存在： \[\mathcal{F}\{x\}(j\omega) = \frac{1}{j(\omega + \omega_0)} + \pi \delta(\omega + \omega_0)\]
    • 注意：此时 \(\mathcal{F}\{x\}(j\omega) \neq X(s)|_{s=j\omega}\)。

结论提炼

  1. 收敛条件：拉普拉斯变换的积分要在 \(t \to \infty\) 时衰减，要求 \(s\) 的实部足够大，以抵消信号可能的增长。
  2. ROC 与极点：本例的极点位于 \(s = -a\)。对于右边信号，收敛域总是位于最右侧极点的右侧复半平面。
