# 第9章 拉普拉斯变换：QMD reveal.js 完整逐页课件

文件说明：

- `laplace_ch9_full_reveal.qmd`：主课件文件。
- `images/`：从原 PDF 逐页渲染得到的页面图片。
- `styles.css`：使页面图片在 reveal.js 中居中、等比例显示。
- `_quarto.yml`：Quarto 项目配置。

使用方法：

```bash
quarto preview laplace_ch9_full_reveal.qmd
```

或生成 HTML：

```bash
quarto render laplace_ch9_full_reveal.qmd
```
